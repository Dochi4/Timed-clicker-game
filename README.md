# Timed Clicker Game

**Repository:** https://github.com/Dochi4/Timed-clicker-game

---

## Description

Timed Clicker Game is a browser-based incremental game built with **React and a 3D interactive environment**.

The primary focus of this project was to gain a deeper understanding of **modern frontend development** while leveraging my background as a **3D artist**. I created this game using React to explore what could be accomplished with **Three.js**, a JavaScript library designed for rendering and interacting with 3D graphics in the browser.

This project allowed me to experiment with combining **interactive UI systems and real-time 3D rendering** inside a web application.

All 3D models used in the game were **created by hand in Autodesk Maya** and textured using **Substance Painter**. The original model and texture files are included in this GitHub repository.

Overall, the project allowed me to work with **more advanced frontend systems than I had previously used**, including real-time rendering, animation loops, and managing interactive state within a React application.

---

## Features

- 3D interactive gameplay using WebGL
- Timed gameplay loop
- Upgrade system for improved clicking efficiency
- Multiple game stages (start, play, upgrade, end)
- Interactive object animations
- Responsive game UI
- React state management using hooks and context

## 3D Asset Pipeline

This project demonstrates a complete **3D asset pipeline for web-based applications**:

1. Models created in **Autodesk Maya**
2. Textures created in **Substance Painter**
3. Models exported and optimized for **Three.js**
4. Integrated into the React application using **React Three Fiber**

All source assets are included in this repository.

---

## Key React Concepts Used

- `useState` — Manage game variables such as score and timers
- `useContext` — Share global game state
- `useEffect` — Handle animations and game events
- `useRef` — Control 3D objects
- `useFrame` (React Three Fiber) — Update animations every render frame

## Development Environment

This project was built using **React + Vite**, which provides a fast development server, hot module replacement (HMR), and optimized builds.

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Dochi4/Timed-clicker-game.git
cd Timed-clicker-game

### Install dependencies
bash
npm install
### Run the development server
bash
npm run dev
The app will run at: http://localhost:5173


```
